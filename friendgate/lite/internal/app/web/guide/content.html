下载和使用 Codex CLI

  1. 安装 Node.js 18 或更新版本。
  2. 安装官方 CLI：npm install -g @openai/codex；也可以不安装，直接运行 npx @openai/codex。
  3. 完成配置后，在项目目录执行 codex。如需确认网关是否可达，可先执行 curl -H "Authorization: Bearer <你的 Key>" <Base URL>/models。

官方入口：developers.openai.com/codex。CLI 的版本和可用模型由官方及你的 ChatGPT 账号权限决定。

需要官方桌面软件时，从同一官方入口下载适用于 macOS / Windows 的 Codex app；安装后也可以在终端执行 codex app 打开桌面应用。桌面应用的登录、版本和功能由 OpenAI 官方控制，本网关只负责 API 连接。

在 VS Code 中使用 Codex 插件

  1. 在 VS Code 扩展市场安装官方 Codex 扩展（发布者 OpenAI）。
  2. 让插件使用与 CLI 相同的用户级 ~/.codex/config.toml；如果插件提供独立的 API Base URL / API Key 设置，则填入本页显示的三项连接信息。
  3. 打开项目文件夹后，从侧边栏启动 Codex。首次使用时按插件提示重新加载窗口。
